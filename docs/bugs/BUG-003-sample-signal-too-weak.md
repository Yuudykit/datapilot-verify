# BUG-003：样例数据下降信号过弱

## 复现与影响

固定种子生成后，6 月净销售额为 908631，7 月为 850371，环比仅 -6.41%，未达到规划的约 -12%，主演示故事不够明显。

## 根因

华东三家问题门店的家电折减和华东其他订单折减不足，同时其他区域随机增长抵消了部分下降。

## 修复

- 三家问题门店 7 月家电金额系数从 0.42 调整为 0.20。
- 华东其他 7 月订单系数从 0.82 调整为 0.65。
- 保持订单数、退款机制和其他区域逻辑不变，避免为目标数字硬编码结果。

## 验证

重新生成后检查环比范围、最大下降区域和文件哈希，并由 Golden Test 固化。
