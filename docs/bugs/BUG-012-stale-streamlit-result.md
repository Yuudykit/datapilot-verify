# BUG-012：新问题失败时残留上一条分析结果

- 日期：2026-08-30
- 模块：Streamlit 用户界面
- 级别：P1
- 状态：已修复

## 现象

连续提交第二、第三个问题时，如果新请求异常、超时或模型未返回有效结果，页面仍从
`st.session_state["result"]` 读取上一条答案，因此用户会误以为旧答案被追加到新回答下面。

## 根因

提交新问题时只在分析成功后覆盖 `result`，分析开始前没有清理旧结果。

## 修复与验证

提交按钮触发后立即清除 `result` 和 `replay`，失败时仅保留当前错误提示。Streamlit
AppTest 页面启动无异常，全量测试保持通过。
