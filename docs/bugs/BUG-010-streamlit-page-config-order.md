# BUG-010：Streamlit 页面配置顺序错误

- 日期：2026-08-30
- 模块：本机用户界面
- 级别：P1
- 状态：已修复

## 现象与根因

页面配置位于缓存资源和应用初始化之后。Streamlit 要求 `st.set_page_config()` 是首个
Streamlit 命令，部分运行方式下会直接阻止页面启动。原因是界面从原型扩展时没有保留该
执行顺序约束。

## 修复与验证

将页面配置移到任何缓存装饰器和资源初始化之前，并增加 Streamlit AppTest 无头启动验收。
AppTest 异常数为 0，`http://127.0.0.1:8767` 返回 HTTP 200，全量测试 `54 passed`。
